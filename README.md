# Visual Line Stimulator for Drosophila

A lightweight Python & Tkinter GUI tool designed to generate dynamic line and bar patterns in real time for *Drosophila melanogaster* visual and behavioral experiments.

## Features
- Real-time generation of moving line/bar patterns.
- Interactive GUI to control speed, direction, spatial frequency, contrast, and colors.
- Standalone Windows executable (`.exe`) available (no Python setup required).

## Quick Start (For Non-Programmers)
1. Go to the **Releases** section on the right side of this repository.
2. Download the latest `.exe` file under **Assets**.
3. Double-click the file to run the application directly on Windows.
